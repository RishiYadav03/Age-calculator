# Age-calculator
This Age Calculator is a responsive and interactive web application built using HTML for structure and Bootstrap for styling and layout. The tool enables users to input their date of birth and instantly calculates their current age in years, months, and days.

✨ Key Features:

Clean and Responsive UI using Bootstrap components like forms, cards, and buttons.

Date Picker Input to easily select the birthdate.

Real-time Calculation using JavaScript (if integrated).

Mobile-Friendly Design that adapts to all screen sizes.

 
🛠 Technologies Used:

HTML – For building the structure of the form.

Bootstrap – For styling and making the UI visually appealing and responsive.

JavaScript – To perform the age calculation logic.
